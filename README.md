# Chicago Taxi - Database Testing & Log Analysis (PostgreSQL & Bash)

##  Descripción del Proyecto
Este proyecto de **Aseguramiento de Calidad (QA)** está centrado en la **validación de integridad de datos**, auditoría de reglas de negocio y **análisis de causa raíz en logs del servidor** para la plataforma de transporte **Chicago Taxi**. 

El objetivo principal fue identificar inconsistencias reportadas por los usuarios y el equipo de desarrollo relacionadas con la disponibilidad de vehículos, lógica de tarifas por clima y discrepancias en reportes de ganancias.

---

##  Tecnologías y Herramientas Utilizadas
* **Base de Datos:** PostgreSQL
* **Lenguaje de Consultas:** SQL (JOINs, CASE, HAVING, Aggregations, Subqueries)
* **Consola / CLI:** Git Bash, Linux Commands (`grep`, `cat`, `mkdir`)
* **Gestión de Entorno:** Conexión a servidor remoto vía cliente PostgreSQL CLI (`psql`)
